# GitHub repository metadata

## About (description)

Open-source React Native (Expo + TypeScript) wallpaper app using the free NexWall Wallpaper API: categories, FlatList infinite-scroll grid, full-screen preview and save to photos with expo-media-library. Handles rate limits (429) and shows remaining quota. MIT licensed starter.
